ที่มาของปัญหาและวัตถุประสงค์ของโครงงาน

❌ ปัญหาของระบบสมาร์ทฟาร์มแบบเดิม

  • ข้อจำกัดด้านระยะทางของ Wi-Fi: แปลงเกษตรอยู่ห่างจากอาคารหลัก ทำให้สัญญาณ Wi-Fi ไปไม่ถึง
  • ข้อมูลสูญหายเมื่ออินเทอร์เน็ตล่ม: ระบบที่ส่งค่าขึ้น Cloud โดยตรงจะขาดช่วงทันทีเมื่อเน็ตฟาร์มหลุด
  • SD Card เต็มและเสื่อมสภาพเร็ว: อุปกรณ์เกตเวย์ที่บันทึกข้อมูลตลอด 24 ชม. มักเกิดปัญหาเมมโมรี่เต็ม
  • ขาดระบบควบคุมและแจ้งเตือนเชิงรุก: เกษตรกรไม่ทราบทันทีเมื่อค่า pH, EC หรืออุณหภูมิวิกฤต

✅ แนวทางการแก้ไขในระบบของเรา

  • ใช้ LoRa 433 MHz: รับ-ส่งข้อมูลระยะไกลข้ามแปลงเกษตร ใช้พลังงานต่ำ และทะลุทะลวงสูง
  • Offline-First MongoDB Buffer: พักข้อมูลบน Raspberry Pi 5 ก่อนซิงค์ขึ้น Server เมื่อเน็ตกลับมา
  • Automated Storage Manager: บีบอัดข้อมูลเก่าเกิน 7 วัน (.json.gz) ย้ายลง USB Flash Drive อัตโนมัติ
  • Closed-Loop Auto Control & LINE Bot: สั่งเปิด-ปิดปั๊ม/พัดลมตามค่าเซนเซอร์อัตโนมัติและแจ้งเตือนเข้า LINE

🔌 SLIDE 4 / 10 • HARDWARE & WIRING PINOUT

การออกแบบฮาร์ดแวร์และการต่อวงจร (ESP32 + LoRa SX1278)

ขาพิน ESP32 ขาพิน SX1278 หน้าที่การทำงาน
3.3VVCCไฟเลี้ยงโมดูล 3.3V (ห้ามต่อ 5V)
GNDGNDกราวด์ร่วม (Common Ground)
GPIO 18SCKสัญญาณนาฬิกา SPI Clock
GPIO 19MISOMaster In Slave Out
GPIO 23MOSIMaster Out Slave In
GPIO 5NSS (CS)Chip Select เลือกชิปวิทยุ
GPIO 26DIO0Interrupt แจ้งเตือนรับ-ส่งข้อมูล
GPIO 14RESETรีเซ็ตโมดูล LoRa

🎛️ ฟีเจอร์ปุ่ม BOOT (GPIO 0) & WiFiManager

ตรวจจับการกดปุ่ม BOOT ค้างไว้ 3 วินาที ใน loop() ตลอดเวลา เพื่อเปิดโหมด Access Point (SmartFarm_Rx_... รหัส smartfarm1234) ตั้งค่า Wi-Fi ผ่านมือถือได้ทันทีโดยไม่ต้องแก้โค้ดใหม่

💡 ไฟสถานะอัจฉริยะ (GPIO 2 Active-LOW)

  • ไฟสีฟ้าติดค้าง: ระบบทำงานปกติ (Normal Mode)
  • ไฟดับแวบ 40-50 ms: จังหวะส่งหรือรับแพ็กเก็ต LoRa สำเร็จ
  • ไฟกะพริบถี่รัว: กำลังกดปุ่ม BOOT เข้าโหมดตั้งค่า AP
Firmware: firmware/esp32_lora_sender & firmware/esp32_lora_receiver
📦 SLIDE 5 / 10 • TELEMETRY DATA STRUCTURE

พารามิเตอร์เซนเซอร์ทั้ง 12 ตัว และโครงสร้างแพ็กเก็ต JSON

{
  "id": "ESP32_NODE_01",
  "ts": 1305,
  "rssi": -45,
  "snr": 10.25,
  "data": {
    "s_temp": 26.5,
    "s_hmd": 60.9,
    "w_temp": 25.4,
    "a_hmd": 72.1,
    "p_water": 6.8,
    "e_water": 1.88,
    "l_int": 46572,
    "s_temp_s": 29.2,
    "w_speed": 1.9,
    "w_level": 77.8,
    "f_rate": 2.4,
    "c_stat": "NORMAL",
    "f_stat": "ACTIVE"
  }
}

📋 รายละเอียดพารามิเตอร์ทั้ง 12 ตัว

  • s_temp / s_hmd : อุณหภูมิดิน (°C) และความชื้นในดิน (%)
  • w_temp : อุณหภูมิน้ำในระบบ (°C)
  • s_temp_s / a_hmd : อุณหภูมิอากาศ (°C) และความชื้นอากาศ (%)
  • p_water : ค่าความเป็นกรด-ด่างของน้ำ (pH 0-14)
  • e_water : ค่าการนำไฟฟ้า/ความเข้มข้นปุ๋ย (EC mS/cm)
  • l_int : ความเข้มแสงอาทิตย์ (Lux)
  • w_speed : ความเร็วลม (m/s)
  • w_level / f_rate : ระดับน้ำในถัง (%) และอัตราการไหล (L/min)
  • c_stat / f_stat : สถานะโหนดและการยืนยันกลับ (Feedback)
LoRa Radio Settings: 433 MHz | SyncWord: 0xF3 | SF7 | BW 125 kHz
🍓 SLIDE 6 / 10 • RASPBERRY PI 5 EDGE GATEWAY

ระบบประมวลผลขอบสนาม (Raspberry Pi 5 Gateway Daemon)

1. Serial Reader & MongoDB Offline Buffer

  • รับสตริง JSON จากพอร์ต /dev/ttyUSB0 (115200 baud)
  • บันทึกลง MongoDB Container (Docker) ทันทีพร้อมตั้งค่า synced: false
  • หากอินเทอร์เน็ตหรือ Wi-Fi ล่ม ข้อมูลทั้งหมดจะถูกเก็บไว้ใน MongoDB บน Pi โดยไม่สูญหาย

2. Batch Sync Client (Auto-Failover)

  • ดึงข้อมูลที่ยังไม่ได้ซิงค์ส่งขึ้น Server ทุกๆ 10 วินาที (Batch ลละสูงสุด 50 รายการ)
  • ส่งไปที่ http://DESKTOP-P4UNEON.local:8000/api/sync.php เป็นหลัก และมี IP สำรองอัตโนมัติ
  • เมื่อ Server ตอบกลับ 200 OK จึงปรับสถานะเป็น synced: true

3. Storage Manager (SD Card Protection)

  • ตรวจสอบเปอร์เซ็นต์การใช้งาน MicroSD Card ทุกชั่วโมง
  • คัดกรองข้อมูลเก่าที่ซิงค์สำเร็จแล้วเกิน 7 วัน บีบอัดเป็นไฟล์ .json.gz ย้ายไปเก็บที่ USB Flash Drive (/media/usb)

4. Auto-Start Systemd Service

  • ติดตั้งเป็นบริการ smartfarm-gateway.service พร้อมเปิด loginctl enable-linger
  • เสียบปลั๊กไฟ Raspberry Pi แล้วระบบพร้อมทำงานทันทีโดยไม่ต้องล็อกอินหรือต่อจอภาพ
Directory: rpi_gateway/main.py, mongo_handler.py, sync_client.py, storage_manager.py

⚙️ SLIDE 8 / 10 • SMART ACTUATOR CONTROL

ระบบควบคุมอุปกรณ์อัตโนมัติ (Auto / Manual Mode & Feedback)

ผู้ใช้งานสามารถกดสลับโหมด AUTO MODE หรือ MANUAL และปรับตั้งค่าตัวเลขเกณฑ์การทำงานอัตโนมัติได้โดยตรงบนการ์ดแต่ละอุปกรณ์:

อุปกรณ์ (Actuator) เซนเซอร์ที่ใช้อ้างอิง เงื่อนไขสั่งเปิด (ON) อัตโนมัติ (ตั้งค่าได้บนเว็บ) การยืนยันสถานะ (Feedback)
🌊 ปั๊มน้ำหลัก (pump_1) ความชื้นดิน (s_hmd) เปิดเมื่อความชื้นในดิน < 65 % PUMP_1_ON_AUTO
💨 พัดลมระบายอากาศ (fan_1) อุณหภูมิอากาศ (s_temp_s) เปิดเมื่ออุณหภูมิอากาศ > 32 °C FAN_1_ON_AUTO
💡 ไฟสังเคราะห์แสง (light_1) ความเข้มแสง (l_int) เปิดเมื่อความเข้มแสง < 30,000 Lux LIGHT_1_ON_AUTO
🧪 วาล์วน้ำสารละลาย (valve_1) ค่าปุ๋ย/การนำไฟฟ้า (e_water) เปิดเมื่อค่า EC ในน้ำ < 1.5 mS/cm VALVE_1_ON_AUTO
Backend Logic: backend/api/controls.php & backend/api/sync.php
📲 SLIDE 9 / 10 • LINE OA BOT & PUBLIC ACCESS

ระบบแจ้งเตือนผ่าน LINE และการเข้าถึงผ่าน DuckDNS

📲 แจ้งเตือนเข้า LINE (Messaging API)

  • เชื่อมต่อกับ LINE Official Account (Messaging API) ผ่าน Channel Access Token
  • เมื่อค่าเซนเซอร์สูงหรือต่ำกว่าเกณฑ์ที่ตั้งไว้ ระบบจะส่งข้อความแจ้งเตือนพร้อมพิกัดโหนดและเวลาเข้าแอป LINE ทันที
  • มีระบบ Cooldown กันสแปม (เลือกได้ตั้งแต่ 30 วินาที, 1 นาที, 5 นาที) และปุ่มทดสอบส่งข้อความเข้า LINE บนหน้าเว็บ

🌐 โดเมน DuckDNS & Public Tunnel

  • ผูกโดเมน http://olmy.duckdns.org:5173 อัปเดต IP อัตโนมัติผ่านสคริปต์ update_duckdns.ps1
  • ตั้งค่า Vite Proxy รวมพอร์ต Frontend และ Backend API ให้เรียกผ่านพอร์ต 5173 เพียงพอร์ตเดียว
  • มีสคริปต์ Start_Public_Tunnel.bat สร้างลิงก์ HTTPS สาธารณะ + QR Code ให้สแกนเข้าดูผ่านเน็ตมือถือ 4G/5G ได้จากทุกที่
Scripts: Start_SmartFarm_Demo.bat, update_duckdns.ps1, Start_Public_Tunnel.bat
